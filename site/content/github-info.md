- GitHub collaboration basics: repositories, branches, pull requests, and merges.

## Recent updates worth a look

- **Copilot code review can now approve pull requests.** Copilot's automated code review can approve PRs directly, tightening the feedback loop for routine changes. Source: [GitHub Changelog](https://github.blog/changelog/).
- **Content exclusions are generally available in the Copilot app and CLI.** Teams can now reliably keep specified files or paths out of Copilot's context across more surfaces. Source: [GitHub Changelog](https://github.blog/changelog/).
- **GitHub Copilot app for Beginners: Run several agents at once.** A practical walkthrough of running parallel Copilot agents in the Copilot app, useful for anyone scaling up agentic workflows. Source: [GitHub Blog](https://github.blog/latest/).
- **How canvases make agentic workflows visible, steerable, and cost-efficient.** A look at using canvases to track and steer multi-step agent work instead of losing it in chat scroll. Source: [GitHub Blog](https://github.blog/latest/).
- **Awesome GitHub Copilot** curates community agents, instructions, and skills for extending Copilot, including ready-made workflow resources worth browsing when building your own. Source: [Awesome GitHub Copilot](https://awesome-copilot.github.com/).
